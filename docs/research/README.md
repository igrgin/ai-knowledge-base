The [application decision register](../designs/application.md#design-decisions) owns current design status, the [roadmap](../roadmap.md) owns completion/authority and [K0](../contracts/k0-foundation.md) owns implemented foundation conventions. Recheck external claims and exact dependencies when selecting a feature design.
