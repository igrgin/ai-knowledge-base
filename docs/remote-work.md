# Project GitHub requirements

Follow the shared GitHub workflow named in [AGENTS.md](../AGENTS.md) for
issues, branches, commits, pull requests, comments, checks, and merges.

- Use the [roadmap](roadmap.md) to map project task IDs to GitHub issues.
- Preserve native branch protection and the required `Tests` check. Use the
  existing application test suites in CI. A fresh technical review and a
  GitHub approval are distinct records.
- Follow the [EGM workflow](egm-workflow.md#implement-an-accepted-scope) for
  implementation review. Include the reviewed revision, checks, findings,
  and limitations in the delivery evidence.
