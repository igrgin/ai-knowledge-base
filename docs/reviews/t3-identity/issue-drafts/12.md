Integrate T3's Google login in development and packaged UI, including return/cancellation/errors, expiry and application logout. The explicit developer launch shortcut must allow IntelliJ/local service startup without signing in or Google credentials, while sign-in-enabled configuration retains Google login. Accepted configuration: the planned `app.auth.enabled` boolean defaults to false in `dev` and true in `prod`; explicit overrides are allowed. Documentation/tests must distinguish defaults from explicit values rather than hard-locking bypass access to a profile.

Integrate expiry behavior under the accepted 30-minute idle/8-hour maximum defaults: preserve the current view and unsent question while prompting for sign-in again, and restore private state only after the same account reauthenticates. Extend the owning feature state/navigation rather than introducing duplicate draft/history storage. Closing/reopening the browser must preserve a still-valid session within both server-enforced limits.
